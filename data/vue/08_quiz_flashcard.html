8강. 일본어/영단어 암기 플래시카드 퀴즈

1. 완성 화면 요구사항 & 핵심 포인트

  • 카드 뒤집기: isFlipped 불리언 상태를 토글하여 앞면(단어)과 뒷면(뜻/발음)을 전환합니다.
  • 정답/오답 카운트: "알아요" / "몰라요" 버튼 클릭 시 점수를 누적하고 다음 문제 인덱스로 순환합니다.

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref, computed } from 'vue'

const cards = ref([
  { word: 'ありがとう', meaning: '고맙습니다 (아리가토우)' },
  { word: 'Resilience', meaning: '회복탄력성' }
])
const idx = ref(0)
const isFlipped = ref(false)
const current = computed(() => cards.value[idx.value])
</script>

<template>
  <div @click="isFlipped = !isFlipped">
    <h2>{{ isFlipped ? current.meaning : current.word }}</h2>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const cards = ref([
  { word: '一期一会 (いちごいちえ)', meaning: '일생에 단 한 번뿐인 만남' },
  { word: '木漏れ日 (こもれび)', meaning: '나뭇잎 사이로 비치는 햇살' },
  { word: 'Serendipity', meaning: '뜻밖의 행운, 우연한 발견' },
  { word: 'Ephemeral', meaning: '수명이 짧은, 덧없는' }
])

const idx = ref(0)
const isFlipped = ref(false)
const knowCount = ref(0)
const unknownCount = ref(0)

const current = computed(() => cards.value[idx.value])

const nextCard = (known) => {
  if (known) knowCount.value++
  else unknownCount.value++
  isFlipped.value = false
  idx.value = (idx.value + 1) % cards.value.length
}
</script>

<template>
  <div class="quiz-box">
    <div class="score-bar">
      <span class="ok">⭕ 알아요: {{ knowCount }}</span>
      <span>{{ idx + 1 }} / {{ cards.length }}</span>
      <span class="no">❌ 몰라요: {{ unknownCount }}</span>
    </div>

    <div class="flashcard" :class="{ flipped: isFlipped }" @click="isFlipped = !isFlipped">
      <div class="hint">{{ isFlipped ? '뜻 (클릭하여 앞면)' : '단어 (클릭하여 뒤집기)' }}</div>
      <div class="word">{{ isFlipped ? current.meaning : current.word }}</div>
    </div>

    <div class="actions">
      <button class="btn-no" @click="nextCard(false)">😅 몰라요</button>
      <button class="btn-ok" @click="nextCard(true)">😎 알아요</button>
    </div>
  </div>
</template>
