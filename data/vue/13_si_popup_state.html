13강. 한국 SI 팝업/전역변수 vs 현대적 모달 & 상태 관리

1. 한국 SI 팝업/전역변수 vs 현대적 상태 관리

🏢 기존 한국 SI 방식

  • window.open()으로 새 창 팝업을 띄우고 opener.document.getElementById()로 부모 창 DOM 조작
  • 브라우저 팝업 차단에 걸리거나, 데이터 흐름 추적이 불가능

🚀 현대적(근대화된) 방식

  • 인앱 모달(Modal): v-if / v-show로 같은 화면 내에서 부드럽게 띄움
  • 단방향 데이터 흐름: 모달에서 선택한 값을 반응형 상태(selectedUser)에 즉시 반영

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref } from 'vue'

const showModal = ref(false)
const selectedDept = ref('미선택')
</script>

<template>
  <div>
    <p>선택된 부서: {{ selectedDept }}</p>
    <button @click="showModal = true">부서 찾기 (모달)</button>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const showModal = ref(false)
const search = ref('')
const selectedDept = ref(null)

const departments = [
  { code: 'D01', name: '클라우드플랫폼팀', lead: '김팀장' },
  { code: 'D02', name: '프론트엔드아키텍처팀', lead: '이팀장' },
  { code: 'D03', name: '데이터엔지니어링팀', lead: '박팀장' }
]

const filteredDepts = computed(() =>
  departments.filter(d => d.name.includes(search.value) || d.code.includes(search.value))
)

const selectDept = (dept) => {
  selectedDept.value = dept
  showModal.value = false
}
</script>

<template>
  <div class="page">
    <h2>🔍 인앱 검색 모달 (window.open 대체)</h2>
    <div class="picker-row">
      <input :value="selectedDept ? `${selectedDept.name} (${selectedDept.code})` : ''" readonly placeholder="부서를 선택하세요" />
      <button class="btn-open" @click="showModal = true">부서 검색</button>
    </div>

    <div v-if="showModal" class="backdrop" @click.self="showModal = false">
      <div class="modal">
        <div class="modal-head">
          <strong>부서 선택</strong>
          <button @click="showModal = false">✕</button>
        </div>
        <input v-model="search" placeholder="부서명 또는 코드 검색..." class="search-inp" />
        <ul class="dept-list">
          <li v-for="d in filteredDepts" :key="d.code" @click="selectDept(d)">
            <span><strong>[{{ d.code }}]</strong> {{ d.name }}</span>
            <span class="lead">{{ d.lead }}</span>
          </li>
        </ul>
      </div>
    </div>
  </div>
</template>
