0강. Vue 3 핵심 문법 & 디렉티브 실전 사전

이 문서는 1강~10강 실전 프로젝트를 만들 때 계속 참고하는 Vue 3 Composition API (<script setup>) 핵심 사전입니다.

1. 반응형 상태 & 양방향 바인딩

ref() / reactive()

화면과 연결되는 데이터를 만듭니다. ref(초기값)은 JS에서 .value로 접근하고, 템플릿에서는 자동으로 풀립니다.

v-model

<input>, <select>, <textarea>의 입력값을 ref 변수와 실시간 양방향 연결합니다.

2. 조건부 렌더링 & 반복문

v-if / v-else-if / v-else

조건이 참일 때만 DOM을 생성합니다. 로그인/제출 완료 화면 분기 등에 사용합니다.

v-show

DOM은 유지한 채 CSS display: none만 토글합니다. 모달이나 자주 여닫는 UI에 적합합니다.

v-for & :key

배열을 순회하며 목록을 그립니다. 각 항목을 구분하기 위해 반드시 고유한 :key="item.id"를 지정하세요.

3. 속성 바인딩, 이벤트, 파생 상태 & 생명주기

:bind (v-bind) & @click (v-on)

:class, :style, :disabled처럼 속성에 JS 값을 연결하고, @click, @submit.prevent로 이벤트를 처리합니다.

computed()

기존 상태로부터 자동 계산되는 값(총합, 필터링된 목록, 완료율 등)을 캐싱하여 반환합니다.

watch() & onMounted()

watch는 특정 값 변경 시 부수 효과(localStorage 저장 등)를 실행하고, onMounted는 컴포넌트가 화면에 붙은 직후 실행됩니다.

4. 한눈에 보는 종합 예제

Vue 3 핵심 문법 종합 샘플 
<script setup>
import { ref, computed, watch, onMounted } from 'vue'

const keyword = ref('')
const items = ref([
  { id: 1, name: 'Vue 3 기초', done: true },
  { id: 2, name: '실전 프로젝트', done: false }
])

const filteredItems = computed(() =>
  items.value.filter(item => item.name.includes(keyword.value))
)

watch(items, (newVal) => {
  console.log('목록 변경됨:', newVal.length)
}, { deep: true })

onMounted(() => {
  console.log('컴포넌트 마운트 완료!')
})
</script>

<template>
  <div style="padding: 16px; font-family: sans-serif;">
    <h3>핵심 문법 테스트</h3>
    <input v-model="keyword" placeholder="검색어 입력..." style="padding: 6px; margin-bottom: 10px;" />
    <ul>
      <li v-for="item in filteredItems" :key="item.id">
        <label>
          <input type="checkbox" v-model="item.done" />
          <span :style="{ textDecoration: item.done ? 'line-through' : 'none' }">{{ item.name }}</span>
        </label>
      </li>
    </ul>
  </div>
</template>
