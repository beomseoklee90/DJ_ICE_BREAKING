12강. 한국 SI 입력폼(<table>) vs 현대적 Flex/Grid 폼

1. 한국 SI 입력폼 vs 현대적 폼 설계

🏢 기존 한국 SI 방식

  • 레이아웃을 잡기 위해 <table><tr><th>라벨</th><td><input></td></tr></table> 남용
  • 저장 시 $('#userName').val()로 수십 개 입력값을 일일이 긁어모음
  • 모바일 화면에서 테이블이 찌그러짐

🚀 현대적(근대화된) 방식

  • CSS Grid / Flex 레이아웃: 화면 크기에 따라 2열 ↔ 1열 자동 전환
  • 단일 반응형 객체(reactive): form 객체 하나에 v-model로 깔끔하게 바인딩
  • JSON 페이로드 그대로 API 전송 가능

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { reactive } from 'vue'

const form = reactive({
  projectName: '',
  manager: '',
  budget: 0,
  priority: '보통'
})
</script>

<template>
  <div>
    <h2>📝 프로젝트 등록 폼</h2>
    <input v-model="form.projectName" placeholder="프로젝트명" />
    <pre>{{ form }}</pre>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { reactive, ref } from 'vue'

const form = reactive({
  projectName: '',
  manager: '',
  startDate: '2026-12-01',
  budget: 5000,
  isPublic: true
})

const submittedJson = ref('')

const submitForm = () => {
  if (!form.projectName.trim() || !form.manager.trim()) {
    alert('프로젝트명과 담당자를 입력해주세요.')
    return
  }
  submittedJson.value = JSON.stringify(form, null, 2)
}
</script>

<template>
  <div class="modern-form">
    <h2>📝 현대적 Grid 입력 폼</h2>
    <div class="form-grid">
      <div class="field full">
        <label>프로젝트명 *</label>
        <input v-model="form.projectName" placeholder="예: 차세대 ERP 구축" />
      </div>
      <div class="field">
        <label>담당자 *</label>
        <input v-model="form.manager" placeholder="홍길동" />
      </div>
      <div class="field">
        <label>시작일</label>
        <input type="date" v-model="form.startDate" />
      </div>
      <div class="field">
        <label>예산 (만원)</label>
        <input type="number" v-model.number="form.budget" />
      </div>
      <div class="field checkbox-field">
        <label><input type="checkbox" v-model="form.isPublic" /> 사내 전체 공개</label>
      </div>
    </div>

    <button class="submit-btn" @click="submitForm">API 전송 데이터 생성</button>

    <pre v-if="submittedJson" class="json-out">{{ submittedJson }}</pre>
  </div>
</template>
