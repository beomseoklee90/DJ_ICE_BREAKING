15강. B2B 기업 고객 가입폼 & 까다로운 정규식 Validation

1. 실무 B2B 폼 검증(Validation)의 핵심 원칙

B2B 서비스 가입은 일반 B2C보다 훨씬 엄격한 데이터 무결성이 요구됩니다. 단순히 if (!email) 수준이 아니라 아래 2가지 원칙을 적용해야 합니다.

  • Touched + Submit 2단계 에러 노출: 사용자가 입력을 시작하기도 전에 빨간 에러가 뜨면 UX가 나빠집니다. 각 필드에 @blur(포커스 이탈) 시 touched[field] = true를 기록하고, 제출 버튼 클릭 시에는 모든 필드를 강제로 touched 처리해 누락된 항목을 한 번에 표시합니다.
  • 정규표현식(RegExp) 전방탐색 활용: (?=...)(긍정형 전방탐색)으로 비밀번호 복잡도를, (?!...)(부정형 전방탐색)으로 B2B 가입에서 금지할 무료 개인 이메일(gmail, naver 등)을 차단합니다.

2. B2B 가입폼 정규표현식 상세 해부

항목정규표현식 & 검증 규칙핵심 설명
사업자등록번호 /^\d{3}-\d{2}-\d{5}$/ 숫자 3자리-2자리-5자리 하이픈 포함 형식 엄격 검증
기업 공식 이메일 /^[a-zA-Z0-9._%+-]+@(?!gmail\.com$|naver\.com$|daum\.net$|kakao\.com$)[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}$/i (?!...) 부정형 전방탐색으로 개인 무료 메일 도메인 차단
담당자 휴대폰 /^01[016789]-\d{3,4}-\d{4}$/ 국내 이동통신 식별번호(010 등) + 하이픈 형식 검증
보안 비밀번호 /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{10,20}$/ 소문자·대문자·숫자·특수문자 각 1개 이상 포함, 10~20자
💡 왜 computed로 에러 객체를 만드나요?
errors를 computed로 선언하면 form 값이 바뀔 때마다 자동으로 재계산됩니다. 템플릿에서는 v-if="touched.bizNo && errors.bizNo"처럼 깔끔하게 분기할 수 있습니다.

3. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { reactive, computed } from 'vue'

const form = reactive({
  companyName: '',
  bizNo: '',
  corpEmail: '',
  password: ''
})

const errors = computed(() => {
  const err = {}
  if (!/^\d{3}-\d{2}-\d{5}$/.test(form.bizNo)) {
    err.bizNo = '사업자등록번호 형식(000-00-00000)을 확인하세요.'
  }
  return err
})
</script>

<template>
  <div>
    <h2>🏢 B2B 기업 가입</h2>
    <input v-model="form.bizNo" placeholder="사업자번호 (123-45-67890)" />
    <p v-if="errors.bizNo" style="color:red">{{ errors.bizNo }}</p>
  </div>
</template>

4. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { reactive, ref, computed } from 'vue'

const form = reactive({
  companyName: '',
  bizNo: '',
  corpEmail: '',
  phone: '',
  password: '',
  passwordConfirm: '',
  agreeTerms: false
})

const touched = reactive({
  companyName: false,
  bizNo: false,
  corpEmail: false,
  phone: false,
  password: false,
  passwordConfirm: false,
  agreeTerms: false
})

const isSubmitted = ref(false)

const REGEX = {
  bizNo: /^\d{3}-\d{2}-\d{5}$/,
  corpEmail: /^[a-zA-Z0-9._%+-]+@(?!gmail\.com$|naver\.com$|daum\.net$|kakao\.com$|hanmail\.net$)[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}$/i,
  phone: /^01[016789]-\d{3,4}-\d{4}$/,
  password: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?]).{10,20}$/
}

const errors = computed(() => {
  const err = {}
  if (form.companyName.trim().length < 2) {
    err.companyName = '법인명(상호)은 2자 이상 입력해주세요.'
  }
  if (!REGEX.bizNo.test(form.bizNo)) {
    err.bizNo = '사업자등록번호는 000-00-00000 형식이어야 합니다.'
  }
  if (!REGEX.corpEmail.test(form.corpEmail)) {
    err.corpEmail = '기업 공식 이메일만 가능합니다. (gmail, naver 등 개인메일 불가)'
  }
  if (!REGEX.phone.test(form.phone)) {
    err.phone = '담당자 연락처는 010-0000-0000 형식으로 입력하세요.'
  }
  if (!REGEX.password.test(form.password)) {
    err.password = '영문 대/소문자, 숫자, 특수문자를 모두 포함한 10~20자여야 합니다.'
  }
  if (!form.passwordConfirm || form.password !== form.passwordConfirm) {
    err.passwordConfirm = '비밀번호가 일치하지 않습니다.'
  }
  if (!form.agreeTerms) {
    err.agreeTerms = 'B2B 서비스 이용약관에 동의해야 가입할 수 있습니다.'
  }
  return err
})

const isValid = computed(() => Object.keys(errors.value).length === 0)

const handleSubmit = () => {
  Object.keys(touched).forEach(k => { touched[k] = true })
  if (!isValid.value) return
  isSubmitted.value = true
}
</script>

<template>
  <div class="b2b-wrap">
    <form v-if="!isSubmitted" @submit.prevent="handleSubmit" novalidate>
      <h2>🏢 B2B 기업 고객 서비스 가입</h2>

      <div class="field">
        <label>법인명 (상호) *</label>
        <input v-model="form.companyName" @blur="touched.companyName = true" placeholder="예: (주)안티그래비티" />
        <span v-if="touched.companyName && errors.companyName" class="err">{{ errors.companyName }}</span>
      </div>

      <div class="field">
        <label>사업자등록번호 *</label>
        <input v-model="form.bizNo" @blur="touched.bizNo = true" placeholder="123-45-67890" />
        <span v-if="touched.bizNo && errors.bizNo" class="err">{{ errors.bizNo }}</span>
      </div>

      <div class="field">
        <label>기업 공식 이메일 *</label>
        <input v-model="form.corpEmail" @blur="touched.corpEmail = true" placeholder="admin@company.co.kr" />
        <span v-if="touched.corpEmail && errors.corpEmail" class="err">{{ errors.corpEmail }}</span>
      </div>

      <div class="field">
        <label>담당자 연락처 *</label>
        <input v-model="form.phone" @blur="touched.phone = true" placeholder="010-1234-5678" />
        <span v-if="touched.phone && errors.phone" class="err">{{ errors.phone }}</span>
      </div>

      <div class="field">
        <label>관리자 비밀번호 *</label>
        <input type="password" v-model="form.password" @blur="touched.password = true" placeholder="대/소문자+숫자+특수문자 10~20자" />
        <span v-if="touched.password && errors.password" class="err">{{ errors.password }}</span>
      </div>

      <div class="field">
        <label>비밀번호 확인 *</label>
        <input type="password" v-model="form.passwordConfirm" @blur="touched.passwordConfirm = true" placeholder="비밀번호 재입력" />
        <span v-if="touched.passwordConfirm && errors.passwordConfirm" class="err">{{ errors.passwordConfirm }}</span>
      </div>

      <div class="field">
        <label class="chk">
          <input type="checkbox" v-model="form.agreeTerms" @change="touched.agreeTerms = true" />
          [필수] B2B 기업 서비스 이용약관 및 개인정보 처리방침 동의
        </label>
        <span v-if="touched.agreeTerms && errors.agreeTerms" class="err">{{ errors.agreeTerms }}</span>
      </div>

      <button type="submit" class="btn-submit">기업 계정 신청하기</button>
    </form>

    <div v-else class="done-box">
      <h2>✅ B2B 가입 신청 완료</h2>
      <p><strong>{{ form.companyName }}</strong> ({{ form.bizNo }}) 계정이 정상 접수되었습니다.</p>
      <button class="btn-submit" @click="isSubmitted = false">돌아가기</button>
    </div>
  </div>
</template>
