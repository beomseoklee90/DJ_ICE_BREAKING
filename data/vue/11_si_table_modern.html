11강. 한국 SI <table> vs 현대적 데이터 그리드

1. 한국 SI 방식 vs 현대적 Vue 3 방식

🏢 기존 한국 SI 방식

  • <table><tr><th><td>에 JSP/jQuery로 HTML 문자열을 직접 조립 (html += '<tr>...')
  • 컬럼이 늘어나면 <td>를 일일이 복사·붙여넣기
  • 체크박스 전체 선택, 정렬 시 DOM을 직접 순회하며 $(this).prop('checked')

🚀 현대적(근대화된) 방식

  • 선언적 컬럼 정의(Schema): columns 배열로 헤더와 데이터 키를 관리
  • 데이터 중심 상태: selectedIds 배열과 computed로 전체 선택/정렬 처리
  • 모바일에서는 overflow-x: auto 또는 카드형 전환 지원

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref } from 'vue'

const columns = [
  { key: 'id', label: '사번' },
  { key: 'name', label: '이름' },
  { key: 'dept', label: '부서' },
  { key: 'status', label: '상태' }
]

const rows = ref([
  { id: 'EMP-01', name: '김대리', dept: '개발1팀', status: '재직' },
  { id: 'EMP-02', name: '이과장', dept: '기획팀', status: '휴가' }
])
</script>

<template>
  <div>
    <h2>📊 현대적 사원 목록 그리드</h2>
    <table border="1" style="width:100%; border-collapse:collapse;">
      <thead>
        <tr><th v-for="col in columns" :key="col.key">{{ col.label }}</th></tr>
      </thead>
      <tbody>
        <tr v-for="row in rows" :key="row.id">
          <td v-for="col in columns" :key="col.key">{{ row[col.key] }}</td>
        </tr>
      </tbody>
    </table>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const columns = [
  { key: 'id', label: '사번' },
  { key: 'name', label: '이름' },
  { key: 'dept', label: '부서' },
  { key: 'salary', label: '연봉(만원)' },
  { key: 'status', label: '상태' }
]

const rows = ref([
  { id: 'EMP-101', name: '김철수', dept: '플랫폼팀', salary: 5200, status: '재직' },
  { id: 'EMP-102', name: '이영희', dept: 'AI연구팀', salary: 6400, status: '재직' },
  { id: 'EMP-103', name: '박민수', dept: '보안팀', salary: 4800, status: '휴직' },
  { id: 'EMP-104', name: '정수진', dept: '플랫폼팀', salary: 5800, status: '재직' }
])

const selectedIds = ref([])
const sortKey = ref('id')
const sortAsc = ref(true)

const sortedRows = computed(() => {
  return [...rows.value].sort((a, b) => {
    const v1 = a[sortKey.value]
    const v2 = b[sortKey.value]
    if (v1 === v2) return 0
    return (v1 > v2 ? 1 : -1) * (sortAsc.value ? 1 : -1)
  })
})

const isAllSelected = computed(() =>
  rows.value.length > 0 && selectedIds.value.length === rows.value.length
)

const toggleAll = () => {
  selectedIds.value = isAllSelected.value ? [] : rows.value.map(r => r.id)
}

const sortBy = (key) => {
  if (sortKey.value === key) sortAsc.value = !sortAsc.value
  else { sortKey.value = key; sortAsc.value = true }
}
</script>

<template>
  <div class="grid-wrap">
    <div class="grid-header">
      <h2>📊 현대적 데이터 그리드</h2>
      <span class="sel-info">선택됨: {{ selectedIds.length }}건</span>
    </div>

    <div class="table-scroll">
      <table class="modern-table">
        <thead>
          <tr>
            <th style="width: 36px"><input type="checkbox" :checked="isAllSelected" @change="toggleAll" /></th>
            <th v-for="col in columns" :key="col.key" @click="sortBy(col.key)" class="sortable">
              {{ col.label }}
              <span v-if="sortKey === col.key">{{ sortAsc ? '▲' : '▼' }}</span>
            </th>
          </tr>
        </thead>
        <tbody>
          <tr v-for="row in sortedRows" :key="row.id" :class="{ selected: selectedIds.includes(row.id) }">
            <td><input type="checkbox" :value="row.id" v-model="selectedIds" /></td>
            <td v-for="col in columns" :key="col.key">
              <span v-if="col.key === 'status'" :class="['badge', row.status === '재직' ? 'ok' : 'off']">
                {{ row.status }}
              </span>
              <span v-else-if="col.key === 'salary'">{{ row.salary.toLocaleString() }}</span>
              <span v-else>{{ row[col.key] }}</span>
            </td>
          </tr>
        </tbody>
      </table>
    </div>
  </div>
</template>
