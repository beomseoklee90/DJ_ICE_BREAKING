      <div class="desc-item">
        <span class="desc-label n4-text">● N4 레벨</span>
        <div class="grammar-sub-title">1. 패턴 중심</div>
        <p style="margin:0 0 5px 0;"><b>[이름] + と申(もう)します</b> : "~라고 합니다"라는 뜻의 통문장 패턴입니다. `です(~입니다)`보다 조금 더 예의를 갖춘 표현입니다.<br>
        <b>よろしくお願(ねが)いします</b> : "잘 부탁드립니다"라는 뜻으로, 자기소개나 인사 끝에 자주 덧붙이는 자연스러운 문장입니다.</p>
        <div class="grammar-sub-title">2. 뉘앙스</div>
        <p style="margin:0;">복잡한 문법보다는 이 두 문장을 하나의 세트로 기억해 두면, 처음 만나는 자리에서 정중하고 단정한 인상을 전달하기 좋습니다.</p>
      </div>

      <div class="desc-item">
        <span class="desc-label n3-text">● N3 레벨</span>
        <div class="grammar-sub-title">1. 문법 구조 해부</div>
        <p style="margin:0 0 5px 0;"><span class="grammar-focus">初(はじ)めまして</span> : 동사 `始(はじ)める(시작하다)`의 ます형에 `て`가 붙어 인사말로 굳어진 형태입니다.<br>
        <span class="grammar-focus">と (조사)</span> : 원래는 명사 뒤에서 "~와/과"라는 뜻으로 자주 쓰이지만, 여기서는 <b>인용</b>을 나타내는 조사로 쓰여 "~라고"라는 뜻이 됩니다.<br>
        <span class="grammar-focus">申(もう)します</span> : 동사 `言(い)う(말하다)`의 겸양어(자신을 낮추는 말)인 `申す`의 정중형입니다.<br>
        <span class="grammar-focus">よろしく</span> : 형용사 `良(よ)い(좋다)`의 어간에 `く`를 붙여 부사로 만든 형태입니다. (직역: 좋게)<br>
        <span class="grammar-focus">お願(ねが)いします</span> : 동사 `願う(바라다)`에 <b>[お + ます형 + する]</b>라는 겸양어 규칙을 적용한 형태입니다.</p>
        <div class="grammar-sub-title">2. 뉘앙스</div>
        <p style="margin:0;">자신을 낮추어 상대를 높이는 정중한 겸양 표현입니다. 비즈니스 환경이나 어느 정도 격식을 차려야 하는 교류회의 첫 만남에서 활용하기 적절합니다.</p>
      </div>

        <p style="margin:0 0 5px 0;"><span class="grammar-focus">〜と言(い)います</span> : 겸양어인 `申す` 대신 일반 동사인 `言う`를 사용하여 `~라고 말합니다(합니다)`로 표현한 문장입니다.</p>
        <div class="grammar-sub-title">2. 뉘앙스</div>
        <p style="margin:0;">`と申します`가 지닌 격식을 조금 덜어내고 싶을 때 주로 사용합니다. 동등한 위치에서 조금 더 친근하게 다가가고자 하는 사교 모임 등에 어울리는 표현입니다. 약간 밝고 부드러운 어조로 말하면 더 자연스럽게 들립니다.</p>
