1강. 회원 정보 제출 화면

1. 완성 화면 요구사항 & 핵심 포인트

  • 양방향 입력(v-model): 이름, 이메일, 비밀번호, 비밀번호 확인 입력창을 ref와 연결합니다.
  • 실시간 유효성 검사(computed): 이메일 형식(@ 포함), 비밀번호 6자 이상, 비밀번호 일치 여부를 실시간으로 계산합니다.
  • 조건부 분기(v-if / v-else): 모든 조건이 충족되면 제출하기 버튼이 활성화되고, 제출 완료 시 환영 화면으로 전환됩니다.

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const name = ref('')
const email = ref('')
const password = ref('')
const passwordConfirm = ref('')
const isSubmitted = ref(false)

const isEmailValid = computed(() => email.value.includes('@') && email.value.includes('.'))
const isPasswordValid = computed(() => password.value.length >= 6)
const isPasswordMatch = computed(() => password.value !== '' && password.value === passwordConfirm.value)
const isFormValid = computed(() => name.value.trim() !== '' && isEmailValid.value && isPasswordValid.value && isPasswordMatch.value)

const handleSubmit = () => {
  if (isFormValid.value) isSubmitted.value = true
}

const resetForm = () => {
  name.value = ''
  email.value = ''
  password.value = ''
  passwordConfirm.value = ''
  isSubmitted.value = false
}
</script>

<template>
  <div class="card">
    <div v-if="!isSubmitted">
      <h2>📝 회원 정보 입력</h2>
      <input v-model="name" placeholder="이름 입력" />
      <input v-model="email" placeholder="이메일 (example@mail.com)" />
      <p v-if="email && !isEmailValid" class="err">올바른 이메일 형식이 아닙니다.</p>

      <input v-model="password" type="password" placeholder="비밀번호 (6자 이상)" />
      <p v-if="password && !isPasswordValid" class="err">비밀번호는 6자 이상이어야 합니다.</p>

      <input v-model="passwordConfirm" type="password" placeholder="비밀번호 확인" />
      <p v-if="passwordConfirm && !isPasswordMatch" class="err">비밀번호가 일치하지 않습니다.</p>

      <button :disabled="!isFormValid" @click="handleSubmit">가입 완료</button>
    </div>

    <div v-else class="success">
      <h2>🎉 가입을 환영합니다!</h2>
      <p><strong>{{ name }}</strong> ({{ email }}) 님, 등록이 완료되었습니다.</p>
      <button @click="resetForm">다시 작성하기</button>
    </div>
  </div>
</template>
