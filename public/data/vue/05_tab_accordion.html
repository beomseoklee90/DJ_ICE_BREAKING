5강. FAQ 아코디언 & 다중 탭 UI

1. 완성 화면 요구사항 & 핵심 포인트

  • 다중 탭 전환: 현재 선택된 탭 인덱스(activeTab)에 따라 동적 클래스 :class를 적용합니다.
  • 아코디언 토글: 질문을 클릭하면 해당 인덱스가 열리고, 같은 질문을 다시 클릭하면 닫히도록 제어합니다.

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref } from 'vue'

const activeTab = ref(0)
const openIndex = ref(null)
const toggle = (idx) => {
  openIndex.value = openIndex.value === idx ? null : idx
}
</script>

<template>
  <div>
    <h2>❓ FAQ 아코디언</h2>
    <button @click="toggle(0)">질문 1</button>
    <p v-show="openIndex === 0">답변 1입니다.</p>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const tabs = ['일반', '결제/환불', '기술지원']
const activeTab = ref(0)
const openIndex = ref(0)

const faqData = [
  [
    { q: '회원가입은 무료인가요?', a: '네, 모든 기본 기능은 무료로 제공됩니다.' },
    { q: '모바일에서도 사용할 수 있나요?', a: '네, 반응형 웹으로 모바일을 완벽 지원합니다.' }
  ],
  [
    { q: '환불 규정이 어떻게 되나요?', a: '결제 후 7일 이내 미사용 시 100% 환불됩니다.' },
    { q: '영수증 발급이 가능한가요?', a: '마이페이지에서 즉시 출력 가능합니다.' }
  ],
  [
    { q: 'Vue 3 문법만 지원하나요?', a: '네, Composition API(<script setup>) 기준으로 동작합니다.' }
  ]
]

const currentFaqs = computed(() => faqData[activeTab.value])

const selectTab = (idx) => {
  activeTab.value = idx
  openIndex.value = 0
}

const toggleFaq = (idx) => {
  openIndex.value = openIndex.value === idx ? null : idx
}
</script>

<template>
  <div class="faq-wrap">
    <h2>❓ 자주 묻는 질문 (FAQ)</h2>
    <div class="tab-bar">
      <button
        v-for="(tab, idx) in tabs"
        :key="tab"
        :class="['tab-btn', { active: activeTab === idx }]"
        @click="selectTab(idx)"
      >
        {{ tab }}
      </button>
    </div>

    <div class="accordion">
      <div v-for="(item, idx) in currentFaqs" :key="item.q" class="acc-item">
        <button class="acc-q" @click="toggleFaq(idx)">
          <span>Q. {{ item.q }}</span>
          <span>{{ openIndex === idx ? '▲' : '▼' }}</span>
        </button>
        <div v-show="openIndex === idx" class="acc-a">{{ item.a }}</div>
      </div>
    </div>
  </div>
</template>
