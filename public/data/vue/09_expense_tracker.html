9강. 미니 가계부 & 카테고리별 지출 분석

1. 완성 화면 요구사항 & 핵심 포인트

  • 수입/지출 내역 등록: 구분(수입/지출), 카테고리(식비, 교통, 급여 등), 금액, 메모를 입력받아 목록에 추가합니다.
  • 잔액 및 합계 계산(computed): 총 수입, 총 지출, 현재 잔액을 실시간으로 계산합니다.
  • 카테고리 필터링: 선택한 카테고리의 내역만 필터링해 볼 수 있습니다.

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref, computed } from 'vue'

const records = ref([
  { id: 1, type: '수입', category: '급여', title: '월급', amount: 3000000 },
  { id: 2, type: '지출', category: '식비', title: '점심 식사', amount: 12000 }
])
const balance = computed(() => records.value.reduce((acc, r) => r.type === '수입' ? acc + r.amount : acc - r.amount, 0))
</script>

<template>
  <div>
    <h2>💰 잔액: {{ balance.toLocaleString() }}원</h2>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const records = ref([
  { id: 1, type: '수입', category: '급여', title: '프리랜서 정산', amount: 1500000 },
  { id: 2, type: '지출', category: '식비', title: '아이스 아메리카노', amount: 4500 },
  { id: 3, type: '지출', category: '교통', title: '지하철 정기권', amount: 65000 }
])

const type = ref('지출')
const category = ref('식비')
const title = ref('')
const amount = ref('')
const filterCat = ref('전체')

const totalIncome = computed(() => records.value.filter(r => r.type === '수입').reduce((s, r) => s + r.amount, 0))
const totalExpense = computed(() => records.value.filter(r => r.type === '지출').reduce((s, r) => s + r.amount, 0))
const balance = computed(() => totalIncome.value - totalExpense.value)

const filteredRecords = computed(() =>
  filterCat.value === '전체' ? records.value : records.value.filter(r => r.category === filterCat.value)
)

const addRecord = () => {
  const num = Number(amount.value)
  if (!title.value.trim() || !num || num <= 0) return
  records.value.unshift({
    id: Date.now(),
    type: type.value,
    category: category.value,
    title: title.value,
    amount: num
  })
  title.value = ''
  amount.value = ''
}
</script>

<template>
  <div class="ledger">
    <h2>💰 미니 가계부</h2>
    <div class="cards">
      <div class="c inc">수입<strong>+{{ totalIncome.toLocaleString() }}</strong></div>
      <div class="c exp">지출<strong>-{{ totalExpense.toLocaleString() }}</strong></div>
      <div class="c bal">잔액<strong>{{ balance.toLocaleString() }}원</strong></div>
    </div>

    <div class="form-row">
      <select v-model="type"><option>지출</option><option>수입</option></select>
      <select v-model="category"><option>식비</option><option>교통</option><option>쇼핑</option><option>급여</option></select>
      <input v-model="title" placeholder="내용" />
      <input v-model="amount" type="number" placeholder="금액" />
      <button @click="addRecord">등록</button>
    </div>

    <div class="filter-bar">
      <span>카테고리 필터:</span>
      <select v-model="filterCat">
        <option>전체</option><option>식비</option><option>교통</option><option>쇼핑</option><option>급여</option>
      </select>
    </div>

    <ul class="rec-list">
      <li v-for="r in filteredRecords" :key="r.id">
        <span>[{{ r.category }}] {{ r.title }}</span>
        <strong :class="r.type === '수입' ? 'plus' : 'minus'">
          {{ r.type === '수입' ? '+' : '-' }}{{ r.amount.toLocaleString() }}원
        </strong>
      </li>
    </ul>
  </div>
</template>
