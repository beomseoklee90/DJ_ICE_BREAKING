6강. 실시간 투표 & 결과 막대 그래프

1. 완성 화면 요구사항 & 핵심 포인트

  • 득표율 계산(computed): 총 투표수 대비 각 항목의 퍼센트(%)를 계산합니다.
  • 동적 스타일(:style): 막대 그래프의 width를 득표율에 맞춰 실시간으로 늘립니다.
  • 중복 투표 방지: hasVoted 상태로 이미 투표한 경우 다시 투표하지 못하게 막고, 재투표(초기화) 버튼을 제공합니다.

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref, computed } from 'vue'

const options = ref([
  { id: 1, label: 'Vue 3', votes: 5 },
  { id: 2, label: 'React', votes: 3 },
  { id: 3, label: 'Svelte', votes: 2 }
])
const hasVoted = ref(false)
const totalVotes = computed(() => options.value.reduce((s, o) => s + o.votes, 0))
</script>

<template>
  <div>
    <h2>📊 선호 프레임워크 투표</h2>
    <p>총 {{ totalVotes }}표</p>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const options = ref([
  { id: 1, label: 'Vue 3 (Composition API)', votes: 12 },
  { id: 2, label: 'React 19', votes: 9 },
  { id: 3, label: 'Svelte 5', votes: 4 }
])
const hasVoted = ref(false)
const votedId = ref(null)

const totalVotes = computed(() => options.value.reduce((sum, o) => sum + o.votes, 0))

const getPercent = (votes) => {
  if (totalVotes.value === 0) return 0
  return Math.round((votes / totalVotes.value) * 100)
}

const vote = (opt) => {
  if (hasVoted.value) return
  opt.votes++
  hasVoted.value = true
  votedId.value = opt.id
}

const resetVote = () => {
  if (votedId.value) {
    const target = options.value.find(o => o.id === votedId.value)
    if (target && target.votes > 0) target.votes--
  }
  hasVoted.value = false
  votedId.value = null
}
</script>

<template>
  <div class="poll-box">
    <h2>📊 가장 좋아하는 프론트엔드 프레임워크는?</h2>
    <p class="sub">총 참여자: {{ totalVotes }}명</p>

    <div v-for="opt in options" :key="opt.id" class="opt-item">
      <button
        class="opt-btn"
        :class="{ selected: votedId === opt.id }"
        :disabled="hasVoted"
        @click="vote(opt)"
      >
        <span>{{ opt.label }}</span>
        <span>{{ opt.votes }}표 ({{ getPercent(opt.votes) }}%)</span>
      </button>
      <div class="bar-bg">
        <div class="bar-fill" :style="{ width: getPercent(opt.votes) + '%' }"></div>
      </div>
    </div>

    <button v-if="hasVoted" class="reset-btn" @click="resetVote">투표 취소 / 다시 선택</button>
  </div>
</template>
