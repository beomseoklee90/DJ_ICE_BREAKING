4강. 장바구니 & 수량/쿠폰 계산기

1. 완성 화면 요구사항 & 핵심 포인트

  • 상품 추가 & 수량 증감: + / - 버튼으로 수량을 조절하고 0 이하로 내려가지 않게 제어합니다.
  • 할인 쿠폰 적용: 10% 할인 쿠폰 체크박스 또는 선택에 따라 할인 금액을 계산합니다.
  • 무료배송 조건(computed): 상품 합계가 30,000원 이상이면 배송비 0원, 미만이면 3,000원을 자동 합산합니다.

2. 기본 뼈대 코드 (Starter Code)

Starter Code (기본 뼈대) 
<script setup>
import { ref, computed } from 'vue'

const cart = ref([
  { id: 1, name: '무선 키보드', price: 25000, qty: 1 },
  { id: 2, name: '게이밍 마우스', price: 18000, qty: 1 }
])
const useCoupon = ref(false)
const subtotal = computed(() => cart.value.reduce((sum, item) => sum + item.price * item.qty, 0))
</script>

<template>
  <div>
    <h2>🛒 장바구니</h2>
    <div v-for="item in cart" :key="item.id">
      {{ item.name }} - {{ item.price.toLocaleString() }}원 x {{ item.qty }}
    </div>
    <p>합계: {{ subtotal.toLocaleString() }}원</p>
  </div>
</template>

3. 완성 정답 코드 (Solution Code)

Solution Code (완성 정답) 
<script setup>
import { ref, computed } from 'vue'

const cart = ref([
  { id: 1, name: '기계식 키보드', price: 29000, qty: 1 },
  { id: 2, name: '장패드', price: 9000, qty: 1 }
])
const useCoupon = ref(false)

const subtotal = computed(() => cart.value.reduce((sum, i) => sum + i.price * i.qty, 0))
const discount = computed(() => (useCoupon.value ? Math.round(subtotal.value * 0.1) : 0))
const shippingFee = computed(() => (subtotal.value - discount.value >= 30000 || subtotal.value === 0 ? 0 : 3000))
const finalTotal = computed(() => subtotal.value - discount.value + shippingFee.value)

const changeQty = (item, delta) => {
  item.qty = Math.max(1, item.qty + delta)
}
const removeItem = (id) => {
  cart.value = cart.value.filter(i => i.id !== id)
}
</script>

<template>
  <div class="cart-box">
    <h2>🛒 장바구니 & 결제 계산기</h2>
    <div v-for="item in cart" :key="item.id" class="cart-item">
      <div>
        <strong>{{ item.name }}</strong>
        <div class="price">{{ item.price.toLocaleString() }}원</div>
      </div>
      <div class="qty-ctrl">
        <button @click="changeQty(item, -1)">-</button>
        <span>{{ item.qty }}</span>
        <button @click="changeQty(item, 1)">+</button>
        <button class="del" @click="removeItem(item.id)">삭제</button>
      </div>
    </div>

    <label class="coupon">
      <input type="checkbox" v-model="useCoupon" />
      10% 할인 쿠폰 적용
    </label>

    <div class="summary">
      <div><span>상품 금액</span><span>{{ subtotal.toLocaleString() }}원</span></div>
      <div><span>쿠폰 할인</span><span class="red">-{{ discount.toLocaleString() }}원</span></div>
      <div><span>배송비 (3만원 이상 무료)</span><span>{{ shippingFee === 0 ? '무료' : shippingFee.toLocaleString() + '원' }}</span></div>
      <div class="total"><span>총 결제금액</span><span>{{ finalTotal.toLocaleString() }}원</span></div>
    </div>
  </div>
</template>
